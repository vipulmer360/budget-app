# Workspace Rules for Budget App

## STRICT GIT COMMAND CONTROL
- **NEVER** run `git commit` or `git push` unless the user explicitly orders it in their text request (e.g. "git commit karo" or "git push karo").
- Even if a fix or feature is 100% complete and tested, **DO NOT** execute any git commit or push automatically.
- Always wait for explicit user approval for any git operations.
